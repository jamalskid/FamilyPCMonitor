# Security policy

## Supported versions

Security fixes are currently accepted for the latest source on the default branch. The project is an early development release; published binary releases are not yet provided.

## Reporting a vulnerability

Do not post active webhook URLs, bot tokens, database files, or exploitable vulnerability details in a public issue. Use GitHub's **Report a vulnerability** feature on the repository's Security tab once enabled. Until a public repository exists, contact the maintainer privately through their GitHub profile. Include affected version/commit, impact, and reproduction steps without real credentials.

If a webhook URL or token is accidentally exposed, delete or rotate it in Discord immediately. Removing it from a later commit does not remove it from Git history.
